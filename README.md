# fixpot's Armor HUD

A minimalistic, vanilla-like armor HUD for **Minecraft 26.3 Fabric**.

This project is based on **uku's Armor HUD 0.13.0** / the original Armor HUD by BerdinskiyBear, and is maintained by **fixpot47**.

## Features

- Shows equipped armor in a compact vanilla-like HUD
- Low-durability warning
- Durability bar, number, or percentage display
- Horizontal and vertical layouts
- Multiple anchors and styles
- Optional bossbar, status-effect and subtitle shifting
- Optional armor-breaking warning sound
- Config screen through **FixLib**

## Requirements

- Minecraft **26.3**
- Fabric Loader **0.19+**
- **FixLib 2.2.0+**
- Fabric API

## Build

Run:

```bash
gradle build
```

The mod JAR will be generated in `build/libs/`.
